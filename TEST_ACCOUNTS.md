## 🚀 Як створити акаунти в базі даних

### Варіант 1: Через SQL скрипт (рекомендовано)

```bash
mysql -u root -p ai_tourism_companion < database/test_users.sql
```

### Варіант 2: Через MySQL клієнт

1. Відкрийте MySQL Workbench або інший клієнт
2. Підключіться до бази `ai_tourism_companion`
3. Виконайте SQL скрипт `database/test_users.sql`

### Варіант 3: Через реєстрацію на сайті

Якщо база даних вже налаштована, ви можете зареєструвати новий акаунт через форму реєстрації на http://localhost:3000/login

## ⚠️ Важливо

- Ці акаунти призначені тільки для тестування
- Змініть паролі перед використанням у production
- Переконайтеся, що база даних створена та ініціалізована (`database/init.sql`)
