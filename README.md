# AI Tourism Companion - Web Application

Веб-додаток для системи AI Tourism Companion з підтримкою ролей User, Admin та Support.

## Структура проекту

```
game/
├── backend/          # Node.js + Express + JWT API
├── frontend/         # React + Material-UI
├── database/         # SQL скрипти для ініціалізації БД
└── README.md
```

## Функціональні вимоги

### Роль User (Користувач)
- Редагування профілю (ім'я, прізвище, дата народження, стать)
- Перегляд та створення маршрутів
- Перегляд історії відвіданих місць
- Налаштування (окометрія, голосовий режим)
- AI Чат-бот
- Вбудована навігація
- Бронювання
- Cultural Context Translator
- AR-реконструкція

### Роль Admin (Адміністратор)
- Увімкнути/Вимкнути моніторинг локації
- Отримати оцінку безпеки району (AI Safety Advisor)
- Залишити відгук про подію/маршрут
- Переглянути маршрут
- Зануритися у AR-реконструкцію
- Переглянути історію відвіданих місць

### Роль Support (Технічна підтримка)
- Переглянути список тікетів підтримки (чати скарг)
- Надати допомогу користувачам
- Налаштувати CloudFire
- Управління запитами підтримки
- Переглянути логи
- Моніторинг серверів та мережі
- Управління помилками
- Оновлення ПЗ та бібліотек
- Підтримка API
- Контроль бекапів (створити, архівувати, відновити)
- Прозвітувати про помилку для баг-фіксів

## Встановлення та запуск

### 1. Встановлення залежностей

```bash
npm run install-all
```

### 2. Налаштування бази даних

1. Створіть MySQL базу даних
2. Виконайте SQL скрипт з `database/init.sql`
3. Створіть файл `backend/.env` на основі `backend/.env.example`:

```env
PORT=5000
JWT_SECRET=your_super_secret_jwt_key_here
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=ai_tourism_companion
DB_PORT=3306
```

### 3. Запуск проекту

#### Розробка (одночасно backend + frontend):
```bash
npm run dev
```

#### Окремо:

Backend:
```bash
cd backend
npm run dev
```

Frontend:
```bash
cd frontend
npm start
```

## API Endpoints

### Авторизація
- `POST /api/auth/register` - Реєстрація
- `POST /api/auth/login` - Вхід
- `GET /api/auth/me` - Отримати поточного користувача

### Профіль (4 запити до БД)
- `GET /api/profile` - Отримати профіль
- `PUT /api/profile` - Оновити профіль
- `GET /api/translation-settings` - Отримати налаштування перекладу
- `PUT /api/translation-settings` - Оновити налаштування перекладу
- `GET /api/visit-history` - Отримати історію відвіданих місць

## База даних

Використовується MySQL з наданою схемою, що включає:
- Користувачі та ролі
- Профілі користувачів
- Локації та події
- Маршрути та навігація
- Бронювання та платежі
- AR контент
- Системні логи та тікети підтримки
- Бекапи

## Примітки

- Всі компоненти створені з базовою функціональністю
- Деякі функції (AI інтеграція, AR, реальні платежі) потребують додаткової реалізації
- JWT токени зберігаються в localStorage
- Авторизація виконується через JWT Bearer токени
